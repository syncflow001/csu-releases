# CSU

한 컴퓨터의 키보드와 마우스로 옆에 있는 다른 컴퓨터를 함께 쓰는 프로그램입니다. Mac과 Windows를 섞어 쓸 수 있고, 글과 파일도 두 컴퓨터 사이에서 복사해 붙여 넣을 수 있습니다.

## 내려받기

[최신 버전 내려받기](https://github.com/syncflow001/csu-releases/releases/latest) 페이지의 'Assets'에서 컴퓨터에 맞는 파일을 받습니다.

| 컴퓨터 | 파일 | 필요한 것 |
|---|---|---|
| Mac | `CSU-4.1.0.dmg` | macOS 14 이상 (Apple 칩과 인텔 Mac 모두) |
| Windows | `CSU-Setup-4.1.0.exe` | Windows 10 이상, 64비트 |

두 컴퓨터를 같은 Wi-Fi나 같은 공유기에 연결해 두어야 합니다.

## 처음 설치할 때

CSU는 Apple과 Microsoft의 서명을 받지 않은 프로그램이라, 처음 열 때 macOS와 Windows가 한 번 막습니다. [사용 설명서](USER-GUIDE.ko.md) 1장의 순서대로 직접 허용하면 열립니다. 이 페이지에서 받은 파일일 때만 그렇게 하세요.

## 사용 설명서

[USER-GUIDE.ko.md](USER-GUIDE.ko.md) 맨 위의 '빠른 시작'만 따라 해도 설치와 연결은 끝납니다. 그 아래에는 화면 배치, 한/영 키, 파일 옮기기, 문제가 생겼을 때, 제거까지 자세히 적어 두었습니다.
